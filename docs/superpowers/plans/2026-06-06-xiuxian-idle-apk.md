# Xiuxian Idle APK Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the xiuxian idle game as a Flutter Android app and produce a directly installable release APK.

**Architecture:** Create a Flutter app in the repository root with pure Dart domain logic separated from Flutter UI. Game content is configuration-driven, game state is persisted locally, and the UI is a single ink-wash styled mobile screen with dialogs for encounters.

**Tech Stack:** Flutter 3.29.3, Dart 3.7.2, Material 3, `shared_preferences` for local saves, `flutter_test` for unit/widget tests, Android Gradle build for APK output.

---

## Delivery Defaults

- App display name: `修仙小游戏`.
- Target Android package id: `com.feiquan.xiuxian`.
- Generated package id before metadata polish: `com.feiquan.xiuxian_idle`.
- First release APK path: `build/app/outputs/flutter-apk/app-release.apk`.
- Signing: use Flutter/Gradle default local signing for this sideloadable APK unless a release keystore is explicitly provided later. The APK is intended for direct local installation, not Play Store submission.
- Persistence: use `shared_preferences`; preserve `saveVersion` for future migrations.
- Offline gain cap: 8 hours.
- Tick interval: 1 second.
- Autosave interval: 5 seconds and after meaningful actions.
- Activity log cap: 40 entries.
