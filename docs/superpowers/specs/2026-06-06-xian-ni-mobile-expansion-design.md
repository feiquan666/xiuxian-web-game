# 仙逆风移动端扩展设计

## 背景

当前 GitHub Pages 版本已经具备完整的网页修仙循环：修炼、突破、奇遇、境界链、人物羁绊、日志和本地存档。现有问题是玩法表现仍偏文本网页，移动端沉浸感不足，奇遇资源判定存在负数效果误判。

本次扩展目标是在保留现有存档和核心循环的基础上，把页面升级为更像手机游戏的体验，并增加储物袋、说明页、人物形象和属性雷达图。

## 目标

- 修复奇遇负数效果被误判为资源不足的问题。
- 优化移动端网页体验，默认首屏像游戏界面，支持用户点击进入沉浸全屏。
- 增加储物袋系统，让物品和资源进入实际玩法循环。
- 增加图形化游戏说明页，避免大段纯文本。
- 增强人物页，用境界形象和属性雷达图替代纯文字列表。
- 引入更多仙逆风元素，但保持原创表达，避免照搬原著文本。
- 保持 GitHub Pages 静态部署稳定，不依赖后端服务。

## 非目标

- 不引入大型前端框架。
- 不接入账号、云存档、支付或联网排行榜。
- 不把游戏改成复杂装备 RPG；储物袋第一版保持轻量可理解。
- 不使用需要构建链的重资源方案，GitHub Pages 应继续能直接打开。

## Bug 修复设计

`resolveEncounter()` 目前用 `effect.amount < 0` 判断资源消耗。这会把 `heartDemon: -10`、`injury: -10` 这种正向净化效果误判为成本。

新增成本判定规则：

- 成本型资源：`spiritStones`、`pills`、`lifeSpan`、`sectContribution`。
- 可选成本型资源：如后续物品消耗，由独立 `costs` 字段或明确白名单判断。
- 状态净化：`heartDemon`、`injury` 的负数永远不做不足拦截，由 `setNumeric()` 限制到 0。
- 修为负数仍按现有逻辑允许执行并限制到 0，除非未来需求明确把修为作为选择成本。

新增测试：

- 心魔为 0 时可执行 `heartDemon: -10` 的奇遇选项。
- 伤势为 0 时可执行 `injury: -10` 的奇遇选项。
- 灵石不足时仍阻止 `spiritStones: -80`。
- 寿元不足时仍给出明确寿元不足提示。

## 移动端体验设计

页面结构调整为手机游戏壳：

- 根容器使用 `min-height: 100dvh`，并处理 `env(safe-area-inset-*)`。
- 顶部为紧凑状态栏：境界、寿元、重置、沉浸按钮。
- 主内容区内部滚动，避免整页滚动造成底部导航漂移。
- 底部 Tab 固定：`修炼`、`奇遇`、`储物袋`、`人物`、`境界`、`说明`。
- 资源卡片在首屏压缩为核心指标，进阶资源进入人物/储物袋/境界页。
- 主要按钮尺寸不低于移动端可点击标准，减少误触。

全屏策略：

- 浏览器不允许自动全屏，因此不尝试未交互自动全屏。
- 新增“沉浸”按钮，点击后调用 Fullscreen API。
- iOS 不完全支持 Fullscreen API 时仍保持 PWA-like 布局。
- 增加 `theme-color`、`apple-mobile-web-app-capable`、`manifest.webmanifest`。

## 储物袋设计

新增 `inventory` 存档字段，按物品 id 存储数量。

物品配置独立为 `defaultItems`，每个物品包含：

- `id`
- `name`
- `category`: 丹药、法宝、材料、特殊
- `rarity`: 凡、灵、玄、地、天、逆
- `description`
- `tags`
- `usable`
- `effects`

第一版物品：

- 丹药：聚气丹、疗伤丹、清心丹、破境丹
- 法宝：阵旗、雷劫符、护身玉简、古宝残片
- 材料：灵草、灵矿、规则残片、本源碎片、香火
- 特殊：天逆珠碎影、洞府令、命魂灯、残卷

玩法接入：

- 炼丹、购买、奇遇、突破奖励可产出物品。
- 可使用物品直接影响修为、伤势、心魔、突破率、抗劫、法则或本源。
- 储物袋界面展示图标、稀有度、数量和用途标签，不做纯文本列表。

## 资源扩展设计

当前资源较多，本次不再无限增加字段，而是强化已有字段和物品关系。

核心资源：

- 修为、寿元、灵石、丹药、战力
- 道心、悟性、根骨、气运
- 心魔、伤势

高阶资源：

- 意境、法则、本源、抗劫、香火

香火可作为新增状态字段，也可先作为储物袋材料。如果实现成本需要收敛，第一版先作为物品材料，不进核心状态栏。

## 人物形象设计

人物页新增当前修士形象，不再只显示 NPC 羁绊。

形象分层：

- 凝气/筑基：朴素道袍、洞府、微弱灵光。
- 结丹/元婴：金丹光晕、元婴虚影、护体灵光。
- 化神/问鼎：红尘意境、星域气息、问天门影。
- 涅境/空境：法则纹路、本源光轮、虚空裂隙。
- 天人五衰：衰气、命轮裂纹、寿元警示。
- 半步踏天/踏天：九桥、轮回、天地压迫。

实现方式优先使用 CSS 和内联 SVG，保证静态部署稳定。形象会根据境界、心魔、伤势、持有特殊物出现视觉变化。

## 雷达图设计

人物页新增属性雷达图，用 SVG 或 Canvas 轻量实现。

维度：

- 战力
- 道心
- 悟性
- 根骨
- 气运
- 境界核心

境界核心动态映射：

- 化神前：丹药/法宝准备度
- 化神到问鼎：意境
- 涅境：法则
- 空境后：本源

雷达图跟随状态实时更新，移动端宽度自适应，不引入第三方图表库。

## 游戏说明页设计

新增说明页，采用图形化短说明：

- 修炼循环：修炼 -> 资源 -> 突破 -> 新境界
- 风险循环：心魔、伤势、寿元如何影响突破
- 奇遇选择：奖励、代价、境界专属事件
- 储物袋：物品来源和使用方式
- 属性：雷达图维度说明

每项使用图标、短句、标签和流程箭头，避免大段说明文字。

## 存档迁移

`SAVE_VERSION` 升级到 3。

迁移策略：

- 旧存档没有 `inventory` 时补空对象。
- 旧存档没有新增字段时使用初始值。
- 保留已有 `realmIndex`、修为、资源、NPC 羁绊、日志。
- 新增迁移日志：“储物袋已开，旧物归位。”

## 文件结构

预计修改：

- `index.html`: 新增储物袋/说明面板、沉浸按钮、PWA meta。
- `styles.css`: 移动端壳层、底部导航、人物形象、储物袋网格、说明页、雷达图样式。
- `src/game.js`: 修复成本判定、增加物品配置、库存操作、存档迁移。
- `src/app.js`: 渲染储物袋、说明页、人物形象、雷达图、沉浸按钮。
- `test/game.test.js`: 增加 bug 修复、库存、迁移测试。
- `manifest.webmanifest`: 新增 PWA 配置。

## 验收标准

- 当前截图中的“舍资源避劫”不再因为心魔为 0 显示“资源不足”。
- 真正资源不足仍能被阻止并给出明确提示。
- 手机竖屏打开后底部导航固定，核心操作首屏可见。
- 点击“沉浸”按钮可在支持的浏览器中进入全屏。
- 储物袋有物品图标、数量、稀有度和用途，并至少有一种可使用物品能影响状态。
- 人物页有境界形象和雷达图。
- 说明页不是纯文本，能快速解释核心玩法。
- `npm test` 通过。
- GitHub Pages 直接访问路径不破坏。
